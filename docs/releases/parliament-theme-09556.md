# Omnigo Parliament Signature — 0.9.556

22 Kasım 2026: Parliament mavisi kurumsal tema iki portalın açılış, giriş, çalışma alanı, tablo, pencere ve bildirim yüzeylerine ortak renk katmanı olarak eklendi. Yazı ailesi, ölçüler, hizalamalar, geçiş davranışı ve canlı aktarım işleyişi değiştirilmedi.

- Önceki görünüm **Omnigo Klasik Lacivert** adıyla tema seçiminde korunur.
- Yeni varsayılan **Omnigo Parliament Signature** temasıdır.
- Aysun Yurdakul hesabının varsayılanı sunucu tarafında Klasik Lacivert olarak korunur.
- Yayın yalnız tema ve hesap görünümü kaynaklarını içerir; veritabanı, cron, pazaryeri API bağlantıları ve kuyruklar değiştirilmez.
- Yayın öncesi kaynaklar web kökü dışındaki geri dönüş paketinde saklanır; iki portalın kaynak hashleri ve servis durumu yayın sonrasında doğrulanır.
